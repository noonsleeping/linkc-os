# 副业变现六段实战 + 底层逻辑

## 一句话定位

> 6 段成功副业的共同模式：**真实需求 → 自用产出物 → 出圈 → 轻产品化 → 验证市场 → 决定要不要规模化**。
>
> 不是"想到一个点子去做"，是"自己用着用着就出圈了"。

适用：有专业能力（产品 / 技术 / 设计 / 咨询）但没启动过个人生意的人
不适用：纯粹想"搞快钱"、不愿做内容沉淀的人

## 案例 1：婚礼网页模板（产品化的起点）

### 触发
2012 年结婚。互联网公司圈，朋友更习惯网页请柬而非纸质。**自用做了一套**：含夫妻信息、婚礼信息、客气话、互动地图、wonder list（送礼参考）。

### 出圈
- **不是请柬本身出圈**，是另外一段视频先出圈：用太太生活视频做了一个短片（男方版/女方版配音），微博传播
- 短片的传播力来自**工具教学**——用极简软件（Apple iMovie / GoPro 官方），不是 Final Cut
- "出圈以后顺势推荐请柬服务"——和现在做小红书账号一模一样的逻辑

### 验证市场
- 用搜索引擎指数工具（如 Google Trends / 百度指数）查"婚礼请柬""在线婚礼邀请函"
- 搜索引擎相关搜索 + 电商平台相关搜索 → 都是**客观需求渠道**
- **MVP 习惯**：先做高保真原型 + 讲故事，发到特定群体看反馈

### 定价
专业建站 ¥几百，**直接打 1/5**，¥80-100。"卖出去就满足了"，赚钱本身只是为了**验证需求是否真实**。

### 反思
- 单价 ¥100 不是好生意（每单要人工干预）
- "如果有 AI，可能 2-3 次聊天就能生成个性化网页"——agent 适合做
- 当时没有这个能力，就用 WordPress 多站，每单贴文案 + 微调模板

## 案例 2：装修需求文档（结构打磨 + 全球售卖）

### 触发
装修要找设计师。聊了 7-8 个，选了一个"性价比 + 努力 + 想法 + 能把我的需求还原成设计需求"的设计师（**像产品经理 + 设计师双重角色**）。

聊完发现专业隔阂大。**起念头：写需求文档给设计师**。

### 文档核心思路
两条原则：

#### 原则 1：还原原始需求，不假装半专业
"如果我们装作半专业讲一堆术语，反而引起设计师理解偏差。原始需求是我们最擅长的"

文档结构：
- 我的需求 + 太太的需求（**原始访谈纪要**）
- 想象中的孩子 + 猫，他们处于什么阶段、未来需求
- 我们对这些需求的想法（**特别标注：这些不专业，希望您给专业建议**）
- 风格参考：Instagram / Houzz / 好好住 + 颜色感觉的纯感觉照片（如卧室白绿搭配，找植物 / 公园 / 织物图）
- 动线 + 猫的活动空间（手绘）

#### 原则 2：多用具体化方式
描述故事而非列需求。
> 例：孩子长大后我们希望他能从客厅 → 厨房 → 餐厅 → 儿童房**来回跑**。
> 设计师就知道：地板要平、不能有地砖摩擦力差异、不能有踢脚石凸起。

### 出圈
- 设计师团队主动要这份文档作为**他们的标准文档**给客户用 → **意识到市场需求**
- 在公司做了一次分享（产品圈线下交流活动），又收获大量正向反馈
- 决定开卖

### 售卖
- **国内**：淘宝上架（无需资质、私信发链接）
- 推广：微博 + 垂直社区（好好住、住范儿）+ **地方性垂直社区**（10 年前每个地方论坛都有装修板块）
- 推广策略：**按经济水平筛选地方论坛优先级**——沿海试几个、西部试几个，发现哪类不行就放弃，集中精力做高转化的
- **国际**：翻译成英文 + 加入"供应商管理 + 装修进度管理"两个表格，挂 Gumroad
  - 售出 700+ 份，收入约 ¥3w（定价稍高、上架时间长）
  - 装修太折腾人，后期没法持续更新，下架了

### 没做产品化的原因
"Notion / Airtable 已经够好"——文档化能力 + 公开数据视图功能足以替代狭义 SaaS。
"如果现在做，能接 Slack / 钉钉 / 飞书的服务可能值得做。"

### 不选微博推广的原因
**装修不是大众话题**——转发率低，没装修的人不感兴趣。婚礼请柬是**病毒传播**（喜气、视觉化），装修是**精准触达**。

## 案例 3：在行职场咨询（平台型副业 + 漏斗设计）

### 触发
2015 年果壳孵化"在行"（线下经验售卖平台）。**陈言作为对应供给**支援公司产品。

### 在行解决了"定价焦虑"
平台用算法帮不同行业 / 资历的人定价。用户不用因为不好意思而难以收钱——**这是这个产品的核心价值**。

### 话题选择
陈言能讲的话题非常多：创业、职场（升职 / 面试 / 季度考评）、管理（向上 / 向下 / 平行）、产品设计、产品经理工作沟通技巧。

**优势：近水楼台**——能拿到平台数据：哪些话题稀缺、不同话题的转化率。所以可以**有针对性地做产品 + 定价**。

### 收入与定价演化
- 2 年总收入十几万
- 定价从 ¥399 → ¥599 → 最高 ¥1999 + 团队 workshop

### 价格锚定策略（核心）
单个达人页面有多个话题。每个话题在页面里**功能不同**：
- **主力话题**：投入产出比最高
- **价格锚点话题**：看起来无聊但定价偏高 → 让主力话题显得划算
- **超高价话题**：不打算卖，但传递"这人能聊高级话题"的专业感

### 漏斗设计（最值钱的一招）
**用低单价话题钓出深层需求**。

例：职场咨询里最低价是"改简历"（¥200-300）。
- 表层需求：改简历
- 真实驱动力：**最近在找工作 / 想晋升 / 对现状不满**
- 改简历过程中，**激发用户意识到自己其实需要**：职业规划、销售管理、向上沟通……
- 这些都对应陈言更高客单价的咨询

> **本质**：表层需求 → 触发底层焦虑 → 顺势导向高价值服务。
> 这不是卖咨询，是**高信任路径设计**。

### 为什么不做了
- 线下互动成本太高
- 边际成本几乎不下降
- 2018 年知识付费起来，课程业务边际成本几乎为零 → 行家有更好的变现方式
- 现在账号挂在在行上但属于**关门不开张**状态

## 抽象出的底层逻辑

### 1. 副业起点都是"真实需求 + 自用产出物"
- 婚礼请柬：自己结婚要用
- 装修文档：自己装修沟通不畅
- 在行咨询：支援公司产品（顺便变现）
- 特斯拉：自己是车主，懂痛点
- AI：公司在做，家庭也在用

**不是先想到"一个点子去做"，是先解决自己的问题，过程中产出物有人要**。

### 2. "出圈"环节往往不是产品本身
- 婚礼请柬出圈靠**婚礼短片 + 工具教学**
- 装修文档出圈靠**设计师团队主动要 + 公司分享**
- 自媒体账号出圈靠**封面 + 真实场景**

**先有传播性的载体，再顺势推产品**。

### 3. 验证市场的廉价方法
- 搜索引擎指数（Google Trends / 百度指数等）+ 相关搜索
- 电商平台相关搜索（淘宝 / Amazon 等）
- 高保真原型 + 故事，发特定群体看反馈
- **关键不是"赚多少钱"，是"验证这是真需求"**

### 4. 定价的两层逻辑
- **打入价格**：跟随同水平竞品，**不能超出太多**（用户会比价）
- **价格锚点**：用副话题构建专业感，让主力话题显得划算

### 5. 漏斗设计：低门槛触发，高单价转化
- 用低价 / 免费品击中**表层需求**
- 在交付过程中**激发底层焦虑**
- 顺势导向高客单价服务

### 6. 编辑成本决定生意天花板
- 模板生意：每单要微调 → 单价低、不能规模化
- 1v1 咨询：边际成本几乎不下降 → 难规模化
- 知识付费课程：边际成本几乎为零 → 容易规模化
- 自媒体广告：单条内容触达大量用户 → 容易规模化

**做副业前先想清楚：这门生意的编辑成本曲线长什么样？**

### 7. 推广要选符合内容性质的渠道
- 大众话题（婚礼）→ 病毒传播（微博）
- 精准话题（装修）→ 垂直社区 + 地方论坛
- 工具 / 方法论（AI）→ 内容平台（小红书）

**不分场景套同一种推广，是大多数副业失败的原因**。

## 给副业新手的判断框架

陈言隐含的"做不做这个副业"判断流程：

1. **是不是我自己真在用 / 真在解决的问题？** 否 → 别做
2. **这个产出物有没有传播性的载体？**（视频 / 故事 / 视觉效果） 否 → 找一个
3. **市场需求有没有客观信号？**（搜索量 / 同行价格 / 圈子反馈） 否 → 别做
4. **编辑成本怎么样？规模化路径在哪？** 不清楚 → 至少要清楚
5. **能不能用最小成本验证一次？**（高保真原型 / 试卖几单 / 发圈测反馈） 不能 → 想办法
6. **如果验证 OK，扩展时是直接卖、做内容、还是做平台？** 没想清楚 → 走第一种
