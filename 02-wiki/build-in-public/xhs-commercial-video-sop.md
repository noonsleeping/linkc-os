# 小红书商业化视频制作 SOP

## 一句话定位

> 从**接单**到**复盘**的完整链路，让商业化视频既不伤个人账号，又能让品牌方持续合作。
>
> 陈言整套流程的核心理念：**商业内容 ≈ 个人内容**——价值观、形式、个人细节都保持一致。

适用：已有商业合作邀约、需要规范化交付流程的中腰部创作者
不适用：纯个人内容创作者、走带货 / 直播路线

---

## 完整流程

```
接单 → 大纲沟通 → 脚本（AI 辅助）→ 拍摄前确认（大厂特殊）→
拍摄 → 剪辑 → 封面 → 发布 + 数据维护 → 客户复盘
```

### 1. 接单
两类来源：
- **熟客**：品牌官方 / 代理公司主动发需求 → 微信沟通排期 + 特殊要求
- **平台单**：小红书蒲公英平台分配 → 仍然转微信继续沟通

### 2. 大纲沟通
- 常态需求是**先给大纲**（无论文章 / 视频）
- 少数客户直接要脚本
- **陈言的反向操作**：先用 AI 出完整脚本 → 再提炼成大纲给客户。客户看不到脚本

### 3. 脚本（核心 AI 环节）
- **工具**：Google Gemini（理由：模型强 + 风格贴合陈言主题）
- **输入**：品牌 brief + 自己收集的资料 + 传播目的 + 目标受众 + 个人思路
- **输出**：完整脚本
- **耗时**：15-20 分钟
- 备选：ChatGPT（用其记忆能力固化风格）

> **关键判断**：商业内容和个人内容产生冲突的根本原因，不是脚本不好，
> 是**账号本身就不具备做商业内容的空间**。账号定位决定一切。

### 4. 拍摄前确认（大厂客户特殊环节）
大厂会在脚本阶段就要确认：标题 / 封面 / 拍摄场景 / 衣着。

陈言的应对：**提前发几个相关题材的过往视频案例**作为参照。

按甲方专业度分三类：
- **成熟甲方**（大厂、有专人对接）：需求详细、素材齐全 → 无条件执行
- **中等甲方**（资源有限、专业度不足）：需求模糊 → 给模板、建议补充内容
- **不懂传播的甲方**（外企、小团队、新业务、技术公司）：只懂产品 → 先科普小红书传播逻辑，给三种方案，**有意引导到希望的方向**

### 5. 拍摄
- **场地**：干净、安静
- **A-Roll**：自己口播（用 iPhone 14 Pro 前置摄像头，看屏幕配合提词器；商业合作要求表达准确性高）
- **B-Roll**：根据需要补充素材
- **脚本差异**：商业合作要逐字稿（给客户审核）；自己的内容只写提示

> **设备无所谓**——影响账号质量的因素排序：表现力 > 账号定位 > 文本 >>> 设备。
> **核心理念**：能不换设备就不换，避免学习成本和操作习惯改变。

### 6. 剪辑
- **工具**：剪映（不是大量生成式 AI）
- **最常用**：字幕识别（语音转文字 + 时间线对齐，每条视频必用）
- **关键 AI 功能**：涂抹 / 擦除（物体跟踪 + 去除）
  - 真实案例 1：[云服务品牌 A] × [芯片品牌 B] 联合活动，视频不能出现合作方 logo → AI 抹掉
  - 真实案例 2：[消费电子品牌 C] 推广，无意带了 [竞品智能手表] → AI 抹掉
  - 这功能解决的是**合规问题**，不是效率问题

### 7. 封面（陈言重点环节）
- 经历过 2-3 次大改版
- 当前流程：试拍 → AI 特效 → AI 笔条 → 抓眼球短文案 → 合成
- **转化率提升 50-60%**

封面演化史：
1. 早期：抠表情 + Unsplash 免费图 + 文案 → 千篇一律
2. MrBeast 启发：AI 生图 + 夸张场景
3. 当前：Gemini 2.5 Flash（Nanobanana 模型）+ 字节豆包/极梦
4. 文案：极梦生成中文字（风格感强）→ PS 合成

> **双标题机制**详见 [[xhs-methodology#五、封面：从-5-到-10-转化率]]

### 8. 发布 + 数据维护
- 不直接买量
- **私域调动**：维护多个微信群 + 小红书群，发文案请大家推荐 / 评论
- **评论引导**：给粉丝写评论方向建议（很多用户不擅长写评论）
- **激励**：把厂商纪念品做抽奖，拉高评论积极性

### 9. 流量监测 + 调整
- 流量异常时与客户沟通
- **不轻易改视频内容**（成本太高）
- **可改**：标题 / 标签 / 封面（虽然平台可能限流，但陈言倾向积极改）
- 案例：[地图导航品牌] 广告，第一版封面是手机+地图界面（普通），改成"陈言站在纽约街景里 + 地面是地图界面"，数据明显回升

### 10. 客户复盘
- 不是正式报告，**一段描述**就够
- 主要给代理 / 广告公司做复盘（小红书外部导流弱，看互动数据：点赞 / 收藏 / 转发 / 评论）
- 挑亮点：分享高 = 引导有效；收藏高 = 产品实用、有转化潜力
- **目的是关系维护**，成本低、回报长期

## 哪些环节可以交给 AI / 团队？

陈言的两个判断标准：
1. **AI / 团队要能比我做得好 3-5 倍**，或在规模上更便宜（光节省时间不够，因为现在已经很快了）
2. **必须自己做的**：
   - **视频录制**：必须自己露脸，不用数字人，不找替身——账号形象的核心
   - **重要客户的前期沟通**：即使有助理，也要参与

## 给新手的一句话

> 这套流程里没有一步是一开始就规划好的。**做账号就像做产品**，平台、用户、客户、选题都不确定。
>
> **能做的就是建立一套快速验证想法的流程。** 有了想法马上验证，找到适合自己的科学的验证方式。
